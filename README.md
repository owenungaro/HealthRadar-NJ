# HealthRadarNJ
CS546 Final Project

How to use:

Your .env file should contain:
MONGO_URI=mongodb://localhost:27017
MONGO_DB_NAME=healthradar_nj
SESSION_SECRET=secret
PORT=3000
RUN_SEED=FALSE
CREATE_ADMIN=FALSE

Where RUN_SEED and CREATE_ADMIN should be set to true on your first run of the code. Make sure to turn it off after you first run the code for the future.
